# 8gent Code wiki

8gent Code is an open source terminal coding assistant. It runs in your terminal, reads and edits your project, runs commands with your permission, and uses a local model by default. Hosted models are opt-in and need an API key you set yourself.

## Who it is for

- **Users** who want a coding assistant in the terminal that works without an account or a cloud key.
- **Contributors** who want to build, test, or extend 8gent Code from source.
