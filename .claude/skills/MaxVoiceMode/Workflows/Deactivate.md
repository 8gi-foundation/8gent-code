# Deactivate

Turn MaxVoiceMode off.

## Steps

1. Speak one final line confirming the mode is off. Keep it short.
   - "Voice mode off. Back to working in respectful silence."
2. Stop all narration. No further `say` calls for the rest of the task
   unless the user re-activates or a Work Sign-Off voice line is required by
   the 8GI protocol (that is separate from this mode).
3. Continue the actual work normally in text.

## Do not

- Sneak in "one last joke" after deactivation. Off means off.
- Keep narrating quietly. The user asked for silence - honour it.
