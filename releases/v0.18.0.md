# v0.18.0

> Released: 2026-10-01

No breaking changes. This is a minor release: a clean upgrade from 0.17.0 (the last version on npm; 0.17.3 was never published), no
migrations and no config changes required.

## Highlights

- **Bare-machine install** - `npm install -g` works on Linux without Python or a compiler; terminal tabs explain how to enable themselves when `node-pty` is missing (#3259).
- **web_fetch stays on the public internet** - private, loopback and metadata destinations are refused, and every redirect is re-checked (#3255).
- **Prompt cache friendly** - the system prompt and tool list are byte-stable within a session (#3258).

- **Local models can use tools now** - A harness-side tool-calling protocol lets
  any local model run agentically, even when its chat template rejects a native
  `tools` payload (the LM Studio gemma coder, for example, used to 400 on tools and
  fall back to the cloud). The harness teaches the model a fenced `tool_call` JSON
  format, parses it with a string-aware scanner that survives braces and code fences
  inside argument values, executes the calls, and loops. Turn it on with
  `--text-tools`, or it is selected automatically for `lmstudio` and `ollama`
  providers. Your tools stay on your machine.
- **Vessel verification (MVP)** - A standalone agent vessel can now prove its own
  identity and report health, with health-record tests and board-plane monitoring.
- **Hands-free surfaces** - `EIGHT_AUTO_APPROVE` lets trusted surfaces run without a
  per-action approval prompt, for voice and other no-keyboard contexts.
- **Adaptive build pipeline routing** - Build-intent messages in the TUI now route
  automatically to the adaptive three-model pipeline, so "build me X" just works.
- **Discovery-call agent** - A new personality agent runs an iterative investigation
  flow for scoping and discovery conversations.

## Improvements

- Providers: an `openrouter/auto` failover chain (llama-3.3-70b then a free
  llama-3-8b) so a downed model resolves to a healthy one.
- RPC: `session.create` accepts a custom `systemPrompt`; RPC sessions load all tool
  categories; provider runtime is auto-detected from the model prefix.
- Computer use: the vision model is auto-selected at loop startup; click coordinates
  are emitted for the screen-marker overlay.
- Daemon: a new `fs.register` RPC method maps a workspace id to a root directory.

## Fixes

- Computer use: dangerous key combinations are now actually blocked instead of being
  executed.
- Security: personal data is scrubbed from tracked files.
- Daemon: the delegation channel persists memories instead of dropping them.
- Vessel: uses the personal local orchestrator context rather than the cloud vessel.
- Autonomy: the escalation id format is reconciled between `escalate()` and
  `approve()`.

## Upgrade

```bash
npm install -g @8gi-foundation/8gent-code@0.18.0
```

No migrations, no config changes. To roll back: `npm install -g @8gi-foundation/8gent-code@0.17.0`.
